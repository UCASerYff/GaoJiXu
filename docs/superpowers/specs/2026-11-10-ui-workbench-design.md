# 搞积蓄 V4.05 财务工作台改版设计

## 目标与边界

将现有 14 个一级入口重构为五项顶部导航，在不改变业务模型、数据路径、账户关系、游戏进度、小组件契约和深链行为的前提下，提升日常查账效率与记录体验。本版只做界面、导航和备份功能移除，不改变财务计算口径，不新增真实业务记录。

## 信息架构

顶部主导航固定为：总览、收支、攒钱、科研、冒险。品牌、主导航和“记一笔”主操作集中在窗口顶部，不再使用左侧栏。

- 总览：保留待处理自动记账、净资产、本月收支、预算、账户、目标、最近流水、月历、核对和冒险摘要，重排视觉层级。
- 收支：页内切换流水、账户、预算、报表、固定收支。固定收支工作区包含收入、支出和权益；支出的订阅、待核实账期、支付历史、到期事项、统计与复盘改用单一筛选菜单，避免第三层页签。
- 攒钱：页内切换目标、记录、趋势；保留所有编辑、暂停、归档、删除和账户转账行为。
- 科研：保留独立资料库、回收站、附件与深链，重做月份摘要和计划列表。
- 冒险：保留完整游戏功能及像素风，仅统一外围间距、标题和卡片容器。

原 `SavingsSection` 继续作为路由与深链兼容层；顶部选择主工作区，页内状态记住各工作区上次访问的子页面。旧 `gaojixu://` 地址仍精确打开原功能。

## 视觉系统

采用暖白画布、深墨绿主色、青绿辅助色和珊瑚色警示/支出强调，深色模式使用对应的低亮度层级，不直接反色。财务页面使用现代系统字体，像素字体仅保留在游戏和明确的游戏徽章中。

建立统一的工作区标题、内容宽度、卡片圆角、边框、阴影、状态胶囊、空状态和按钮层级。卡片用于分组，不为每段文字重复加框。金额使用等宽数字并保证长金额可缩放或换行。

## 记录列表

流水与积蓄记录从密集表格改为按日期分组的信息列表：分类或类型图标、主标题、账户去向、备注、状态和右对齐金额形成稳定层级。筛选、搜索、分页、单击编辑、右键菜单和受管记录提示全部保留。

固定收入、固定支出、权益和科研计划采用相同的行组件语言：状态胶囊、次要信息、金额和操作区对齐。空状态提供明确下一步，不展示虚构金额或示例业务记录。

## 编辑器

记账、积蓄、目标、账户、预算、固定收入、固定支出、权益和科研编辑器使用统一结构：简洁标题区、分组内容卡片、清晰的必填/错误提示、固定底部取消与保存操作。

记账和积蓄编辑器突出大金额输入；分类使用可选择卡片，账户与日期保持原有校验和快捷操作。保存、保存并再记一笔、跨币种转账、确认到账、支付核实和附件打开等现有流程不得改变业务语义。

## 备份功能与资料保护

按工作区最新规则移除自动备份、手动完整资料/模块备份和恢复入口及其运行逻辑，删除既有备份数据；保留现用业务数据库、设置、附件、游戏进度和钥匙串凭据。科研回收站是现用业务功能，不视为备份。小组件快照是现用派生数据契约，也不视为用户备份，继续保留。

构建、打包、安装与发布流程不创建预更新备份、升级快照或回滚副本。清理前逐项核对路径与类型，失败即停止并报告，不以空白资料覆盖无法读取的数据。

## 验证与发布

版本由 V4.04 / build 5 升为 V4.05 / build 6。先运行隔离回归和编译检查，再核验真实资料清单与关键数据库可读取性；安装后检查五个工作区、主要编辑器打开与取消、深链、小组件及原有记录/附件/游戏进度。除非需要验证保存修复，不创建真实测试流水。

构建与暂存 App 必须从一开始位于 `.noindex` 容器。完成后删除旧 App、旧安装包、中间构建和既有备份，核对 Spotlight、LaunchServices 与实际路径只保留 `/Applications/搞积蓄.app`。项目目录仅保留可推送源码、资源、文档、测试及最新发行包和校验文件；GitHub 只发布源码和 V4.05 安装包，不上传用户资料、私有附件、备份或凭据。
