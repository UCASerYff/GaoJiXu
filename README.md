# 搞积蓄

独立 macOS 记账与积蓄管理应用，包含个人账本、固定收支、攒钱目标、勇者冒险和桌面小组件。

**当前发行版为 V4.06（构建 7）。** 顶部四项财务工作台采用暖白与墨绿视觉系统，记录列表和编辑器经过重新设计；科研模块已完整移除，且不再提供备份、恢复及旧程序回滚功能。

## 下载与安装

从 [Releases](https://github.com/UCASerYff/GaoJiXu/releases/latest) 下载程序及同名 `.sha256` 文件。V4.06 程序包为 `搞积蓄-4.06.zip`，源码包为 `GaoJiXu-4.06-source.zip`，二者均提供 SHA-256 文件。

1. 支持 macOS 14 或更高版本、Apple Silicon；暂未提供 Intel 版本。
2. 解压 ZIP，将 `搞积蓄.app` 拖入“应用程序”文件夹。
3. 如果 macOS 拦截打开，请先确认软件来源，再进入“系统设置 → 隐私与安全性”，允许该应用打开。发行包使用 Apple Development 签名，未做 Apple 公证。
4. 安装后运行一次，再从系统小组件列表添加本应用的小组件。

下载后可在文件所在目录运行 `shasum -a 256 -c 搞积蓄-4.06.zip.sha256` 核验安装包；源码包可使用同名的 `.sha256` 文件核验。

## 功能

- 顶部四项工作区：**总览、收支、攒钱、冒险**。固定收入、固定支出和权益合并为“固定收支”，保留旧 `gaojixu://` 非科研深链。
- 日常记账、资产账户、账户余额调整、转账、预算、收支报表和周期记账；流水与积蓄记录按日期分组展示。
- 攒钱目标与积蓄记录。固定支出迁入自有库后，确认同币种扣款账户可将已确认支付记为支出，同一支付单号不会重复入账。
- 勇者冒险、装备、技能、宠物、祈愿和成就；游戏资源与真实财务记录分别保存。
- 从菜单或 ⌘, 打开设置，调整外观与模块；提供桌面和通知中心小组件。

### 固定收支

- **固定收入**：保存计划只生成预测，不预设工资、不补记历史。实际收到款项后，选择同币种且未归档的账户并确认到账。同一计划、同一月份只确认一次。
- **固定支出与权益**：由搞积蓄自己的业务库管理订阅、支付历史、权益领取和提醒。预计账单不计入个人支出，只有已确认支付和同币种账户绑定才可写入个人账本。

## 用户数据、附件与隐私

源码及安装包不包含个人记录、账户配置、账单、健康数据、私人附件、API 密钥、浏览器会话或用户备份。新电脑首次打开时创建自己的资料库；GitHub 下载不能恢复个人数据。

- 业务数据目录：`~/Library/Application Support/GaoSeries/Savings/`。
- 数据库或小组件镜像：`~/Library/Group Containers/5G96498KGJ.com.gaojixu.savings/`。
- 设置保存在本应用的 UserDefaults 域；凭据由 macOS 钥匙串管理，不导出到普通文件。
- 公开安装包会删除本机编译路径、源文件索引及扩展属性，再重新签名。签名私钥不在仓库或安装包中。

本版本不提供手动或自动备份、备份恢复、升级快照及旧程序回滚副本。安装和清理只处理程序与中间构建，不删除现用业务资料、设置、附件、游戏进度或钥匙串凭据。小组件现用快照属于业务数据，不作为备份清理。

真实业务历史完整保留。界面采用分页或归档减轻加载；游戏事件最多保留 300 条、抽取记录最多 200 条、词元账户显示采样最多 300 条，累计收益、余额、保底计数、库存与游戏进度独立保存。

## 数据路径与迁移

V4.0 从整合版拆分时保留业务历史、余额、库存、游戏进度、设置和全部附件。独立应用继续使用各自的数据目录，升级或替换应用程序不会删除这些数据。

跨应用迁移使用单独的[离线迁移 CLI](Tools/IntegrateFinance.swift)，仅处理月供。它不会自动查找或停止正在运行的应用，也不创建备份或恢复副本。执行前须停止来源与目标写入并核验输入，给工具提供已冻结的月供 SQLite 一致快照（合并 WAL）；缺失或无法读取的输入不能视为空白。**只构建、安装或打开新版均不代表真实迁移已完成。**

命令格式为 `IntegrateFinance --request /绝对路径/request.json`；`IntegrateFinance --help` 列出字段。请求须明确写入事务 UUID、冻结状态、输入文件 SHA-256、来源修订、目标目录、私有日志目录和共享提交标记位置。工具先核验并暂存月供，准备就绪后才发布提交标记、允许目标接管。已提交的事务核验当前资料，不会用旧输入覆盖后来修改的数据。完整逻辑见[迁移事务](Sources/FinanceIntegrationMigration.swift)。

接收方现用资料、既有联合提交标记及防重复记录必须保留。迁移临时文件、日志和来源原始资料不随源码或程序发布，验收及依赖解除后按授权精确清理。

## 从源码构建

需要完整 Xcode、Python 3 和 Apple Silicon Mac。[构建](scripts/build.sh)、[打包](scripts/package.sh)和[安装](scripts/install.sh)是三个独立步骤。默认脚本使用项目配置的开发签名身份；自行构建需使用自己的 Apple Development 证书，并相应调整签名团队、App Group 权限及小组件工程配置。

```sh
./scripts/build.sh
./scripts/package.sh
./scripts/install.sh
```

[金融整合定向检查脚本](scripts/test_finance_integration.sh)使用隔离资料运行回归，并编译 `build.noindex/IntegrateFinance`。在整合工作区运行前，应先取得总协调的重编译租约。执行该脚本不会迁移真实库，也不代替新版的实际业务或小组件验收。

通过环境变量 `GAO_SIGNING_IDENTITY` 可指定签名证书。修改团队后也需调整 `scripts/install.sh` 中的团队检查。`dist/` 存放本地发行 ZIP 和校验文件，不提交到 Git；上传到 GitHub Releases。

安装器只使用当前版本且通过 SHA-256、签名、Team ID、Bundle ID 与版本核验的 ZIP。展开暂存位于 `.install.noindex`，随后注销并删除精确路径 `/Applications/搞积蓄.app` 的旧程序，再安装新候选并核对内容和签名。无论成功或失败均不创建程序或资料备份；失败时停止并报告，不自动恢复或生成回滚副本。安装器不会启动主程序，系统注册可能拉起 Widget。

- `Sources/`、`Shared/`（如有）与 `Module.swift`：业务和游戏逻辑。
- `GameWorld/` 与 `Resources/`：场景、模型、贴图和其他资源。
- `Host/`：独立入口、设置和联动服务。
- `Widgets/`：小组件；`Tests/`：回归验证。
